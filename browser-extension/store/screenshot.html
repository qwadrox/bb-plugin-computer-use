Browser Bridge for bb

Let your bb agents work in your browser tabs

Agents read pages, click, type and take screenshots in background tabs, while you keep using the browser.

  • Tabs agents open go into an Agent tab group
  • Pause agents from the toolbar popup at any time
  • Talks only to bb on this machine; no analytics

Needs the Desktop & Browser Agent bb plugin. Unofficial: not affiliated with bb or Cua AI.
